Política de Privacidad

Última actualización: Abril 2026

Mi Chamba respeta la privacidad de los usuarios. Esta aplicación no recopila, almacena ni comparte datos personales con terceros.

Información recopilada

No se recopila ningún tipo de información personal.

Datos almacenados

Todos los datos se almacenan únicamente en el dispositivo del usuario mediante almacenamiento local (SQLite). No se transmiten a servidores externos.

Permisos

La aplicación puede solicitar permiso para mostrar notificaciones, utilizado únicamente para recordatorios.

Compartición de datos

No se comparten datos con terceros.

Seguridad

Los datos permanecen en el dispositivo del usuario.

Cambios en la política

Esta política puede actualizarse en el futuro.

Contacto

Puedes contactar al desarrollador para cualquier consulta.
